# SaReGaMidi 0.1.0 Alpha 1

Import scanned Bhatkhande notation, review a Devanagari transcription beside the source, and take it into a DAW as four MIDI tracks — melody, theka, chords and bass. The Analysis tab shows frequent and rare swaras. In Notation, enable **Show chords** to audition alternatives or save a chord for one vibhaag.

## Run on Windows x64

1. Extract the entire ZIP to a folder and open **SaReGaMidi.UI.exe**.
2. For the **framework-dependent** ZIP, install the x64 .NET 11 Desktop Runtime. The **self-contained** ZIP includes this runtime.
3. Offline recognition uses the bundled Tesseract libraries and Hindi model. Install the x64 Microsoft Visual C++ Redistributable if the native OCR libraries fail to load.
4. Select **Import composition**, add your scans in reading order, then open **Transcribe** and choose the taal. Review the draft and save the score before exporting MIDI.

Review ornaments, octave marks, continuation signs and repeat passages against the scan. Recognition has primarily been exercised on the Dadra and Keharwa reference compositions. Clean-machine installation and Mixcraft import are still awaiting user verification.
